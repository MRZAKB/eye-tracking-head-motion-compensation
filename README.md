# Computer Vision-Based Eye Tracking with Head-Movement Compensation

A standard-camera eye-tracking system focused on improving gaze estimation under head movement.

The project investigates head-motion compensation methods to reduce gaze-position errors caused by changes in head pose and to improve the robustness of camera-based eye tracking.

## Research Objective

Conventional camera-based gaze estimation can be affected by head movement.  
This project focuses on separating eye-related gaze changes from head-motion effects and evaluating compensated gaze estimates against raw outputs.

## Main Components

- Standard-camera eye tracking
- Head-pose estimation
- Head-movement compensation
- Raw vs. compensated gaze analysis
- Gaze-position visualization
- Quantitative performance analysis

## Analysis Outputs

The system generates several outputs for evaluating gaze behavior and compensation performance, including:

- Gaze plots
- Heatmaps
- Scanpaths
- Event counts
- Raw vs. compensated gaze comparisons
- Compensation-quality summaries

## Research Status

This is an ongoing independent academic research project.

Final experiments and analyses are currently being completed, with the project being prepared for manuscript development.
